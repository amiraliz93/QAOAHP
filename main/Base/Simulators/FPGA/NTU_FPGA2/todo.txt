## Create Cost function generation unit, with CORDIC function.

Completed on Feb. 16, in 2026.

gen_cost.sv is a unit of cost function generation.

It employed following IP components.

- FP64 multiplier. H*gamma
- FP64 to fixed point converter
- Cordic algorithm for sin, cos generation 
- Fixed point to FP64 converter

Latency is big, 218 clocks.

Tested on gen_cost_tb.sv.
Input data written in gen_cost_tb.sv is generated by gen_cost.py. 
gen_cost.py outputes to gen_cost_in.sv.


- fixed the bug in Control interface (new_statemachine), by which OP_MOV_T2B was not implemented. So, Implemeted OP_MOV_T2B with this bug fix.
