\section{Notations}
For \(n\in\sN\), 
\begin{equation}
    [n] = \cbr{1, 2, ..., n}. 
\end{equation}
In addition, for \(n, i\in \sN\),
\begin{equation}
    \eqlabel{eNn}
    [n]_i = [n]-\cbr{i}.
\end{equation}
Similarly, for \(i, j, k\in[n]\), as,
\begin{equation}
    [n]_{i,j,k} = [n]-\cbr{i,j,k}.
\end{equation}
The document uses also python like notation, for \(n, m\in\sN, n \geq m\),
\begin{equation}
    n:m = \cbr{n,n-1,...,m}
\end{equation}
The document defines a set of binary values \(B\), as,
\begin{equation}
    B = \cbr{0, 1}
\end{equation}
\(\mathbf{i}\) is an imaginary unit that satisfies \(\mathbf{i}^2 = -1\).

For any finite set \(A\), its number of elements is noted as \(\# A\).

We denote number of qbits as \(N\) throughout the documents, and the dimension of the state vector as \(D = 2^N\).

This documents regards \(p\in B^N\) and \(p\in [2^N-1]\) is equivalent definition. Formally, the following equivalence with respect to binary and integer expression is introduced.
\begin{equation}
    \eqlabel{e1}
p = p_N \cdots p_2p_1 \Leftrightarrow p = \sum_{i=1}^N p_i 2^{i-1},
\end{equation}
This documents uses the equivalent expression above without any special note.

Here is an example. if we write
\[
    p = 0000\cdots00101,
\]
then, the following statement,
\[
    p = 5.
\]
is equivalent to the first one.

This documents frequently uses a permutation. Given \(p\in B^N\), we have an expression,
\[
p= p_Np_{N-1}\cdots p_1.
\]
Then \(h: B^N\to B^N\) is a permutation there is an index permutation (bijection) \(\hat{h}: [N]\to[N]\) providing the following relation, 
\begin{equation}
    \eqlabel{ePerm}
    h(p)_i =  p_{\hat{h}(i)}
\end{equation}
Then we denote it as,
\[
    h(p)_i = p_{h i}.
\]
Any mapping of indexes in this documents have an expression as in \eqref{ePerm}. We make any index mappings in this document represent its equivalent permutation as in \eqref{ePerm} without ambiguity. \(h\) here is bijection of \(B^N\to B^N\), and \(\hat{h}\) is also a bijection of \([N]\to [N]\).

\section{Address for 1st qubit mixer operation}
\label{s1stmixer}
Indexes are critical to implement the QAOA system precisely on FPGAs, rather than matrix-vector expression because we must calculate equivalent index expressions when those matrixes operation is implemented on logical circuit. So, the indexing and its relation to operation is defined strictly, from actual easy example to general case.

Considering the series of integer sequence \(j=0,1,...,D/2-1\), and a state vectors \(\psi\), we can determine 2 indexes for mixer operation in the case of 1st qubit as,
\begin{equation}
    \eqlabel{ei}
    p = 2 j, q = 2 j + 1.
\end{equation}
Letting \(p, q\) have the following binary expression,
\[
 p = p_N \cdots p_2 p_1, q = q_N \cdots q_2 q_1,
\]
then we can see for all \(i \in [N]\),
\[
\begin{matrix}
    i \not\in N_1\Rightarrow p_i \neq q_i,\\
    i\in N_1\Rightarrow p_i = q_i,
\end{matrix}
\]
where \(N_n = \cbr{i|i\in [N], i\neq n}\).
So the mixer operation will be,
\begin{align}
    \nonumber
    \psi_p &= \psi_p\cos\beta - \ci\psi_q \sin \beta \\
    \eqlabel{em}
    \psi_q &= -\ci\psi_p\sin \beta  + \psi_q\cos \beta
\end{align}
\section{Addressing for general case of mixer operation}
\label{sAddrGen}
To get 2 index for general case of mixer operation, there are several ways of addressing. In this section, we introduce a method with swapping 2 bits in an index variable used in the case of 1st qubit mixer operation described in the previous section.

Let \(n\) be a current qubit place we are focusing on for mixer operation, \(\hat{p}, \hat{q}\) be indexes of state vector element that should be applied a mixer operation. Assuming we have index expression,
\begin{equation}
    \eqlabel{e4}
    p = p_N\cdots p_n\cdots p_2p_1, q = q_N\cdots q_n \cdots q_2q_1
\end{equation}
we obtain \(\hat{p}, \hat{q}\) as,
\begin{equation}
    \hat{p} = p_N \cdots p_1\cdots p_2 p_n, \hat{q} = q_N \cdots q_1\cdots q_2 q_n.
\end{equation}
Now, we see easily,

then we can see for all \(i = 1,2,...,N\),
\[
\begin{matrix}
    i \not\in N_1 \Rightarrow \hatp_i \neq \hatq_i,\\
    i\in N_1 \Rightarrow \hatp_i = \hatq_i,
\end{matrix}
\]
where \(N_n = \cbr{i|i\in [N], i\neq n}\). Therefore, using these indexes \(\hat{p}, \hat{q}\), we do mixer operation for \(n\)-th qubit as, 
\begin{align}
    \nonumber
    \psi_\hatp &= \psi_\hatp\cos\beta - \ci\psi_\hatq \sin \beta,\\
    \eqlabel{emg}
    \psi_\hatq &= -\ci\psi_\hatp \sin \beta  + \psi_\hatq \cos \beta,
\end{align}
where \(\ci^2 = -1\).
\subsection{Invariance on exchange of qbits for mixer operation}
\label{mixerInvariance}
We further formalize mixer operation here. The sets of indexes pairs that the mixer operation applied is denoted as \(S_1, ...,S_N\) such that,
\begin{equation}
    \eqlabel{eSn}
    S_n = \cbr{\cbr{p, q}| p_n\neq q_n, \forall i\in [N]_n \br{p_i = q_i}},
\end{equation}
where notation \([N]\) and \([N]_n\) is defined in \eqref{eNn}. Note that \(\sum_{i\in [N]}S_i = S\).For example, indexes \(p, q\) defined in the \(n\)-th swapping case of \eqref{e4} satisfy \(\cbr{p, q}\in S_n\), and that of 1st qbit case of \eqref{s1stmixer} satisfy \(\cbr{p, q}\in S_1\).

\textbf{Mixer Operatoin} is defined for all qbit here. The processing of mixer operation can be as following. Picking up each \(n\in [N]\) and then for all \(\cbr{p, q}\in S_n\) 
\begin{align}
    \nonumber
    \psi_{p}' &= \psi_{p}\cos\beta - \ci\psi_{q} \sin \beta, \\
    \eqlabel{emg2}
    \psi_{q}' &= -\ci\psi_{p} \sin \beta + \psi_{q} \cos \beta.
\end{align}
\textbf{Theorem} We can take any order of picking up for \(n\), precisely, we can take any sequence \((n_1, n_2,..., n_N)\) satisfying \(\cbr{n_i|i\in [N]} = [N]\) to apply mixer operations in the order of \(n_1, n_2,..., n_N\)-th qbit. And for any fixed \(n = n_i\) we can take any order of picking up for \(\cbr{p, q}\) from \(S_n\).

\textbf{Proof of the theorem} Because the problem on \(p, q\)is evident we see only problem on \(n\) here. The case we apply mixer operator for qbits \(n,m\in [N], n\neq m\) is considered. Application order \(m \to n\) and \(n\to m\) is considered respectively, then it is proved that both results are the same. 

For a result with the order of \(n\to m\) is shown firstly. For any \(p=0,1,...,D/2-1\), there uniquely exists \(q\) that satisfies \(\cbr{p, q}\in S_{m}\) and a pair \(\cbr{a, b}\) that satisfies \(\cbr{p, a}, \cbr{q, b}\in S_{n}\) from the definition of \eqref{eSn}. And because  operator of \(n\)-th qbit is already applied, then using \eqref{emg2},
\begin{align}
    \nonumber
    \psi_{p}' &= \psi_p \cos\beta - \ci\psi_q \sin \beta, \\
\end{align}
But because operation for \(\cbr{p, a}, \cbr{q, b}\in S_n\) at \(n\)-th qbit have been done already, we can substitute its result, therefore, using \eqref{emg2} again, obtain 
\begin{align}
    \nonumber
    \psi_{p}' &=  (\psi_{p}\cos\beta - \ci\psi_{a} \sin \beta)\cos\beta - \ci(\psi_q \cos \beta - \ci \psi_b \sin \beta) \sin \beta, \\
    \eqlabel{eqn2m}
    & = \psi_p\cos^2 - \psi_b\sin^2\beta - \ci\br{\psi_a \sin\beta\cos\beta + \psi_q\cos\beta\sin\beta},
\end{align}
where \(p\neq q, a\neq b\). 

Before going to the opposite case, we see \(\cbr{a, b}\in S_{m}\).

Proof: we have,
\begin{align*}
    &a_n \neq p_n\land \forall i\neq n(a_i = p_i), \quad\because \cbr{p, a}\in S_n,\\
    & b_n \neq q_n\land \forall i\neq n(b_i = q_i), \quad\because \cbr{q, b}\in S_n, \\\
    &q_m\neq p_m\land\forall i\neq m (q_i=p_i), \quad\because \cbr{p, q}\in S_m.
\end{align*}
The above logic provides, \(a_m = p_m, b_m = q_m, q_m\neq p_m\)  and \(n\neq m\), that is, from the transitive law \footnote{\(x = y, y=z\Rightarrow x=z\)} of equation, \(a_m \neq b_m\). In addition, for all \(i\neq m\), if \(i\neq n\) then \(a_i = b_i\). For \(i\neq m \land i=n\), if we assume \(a_n\neq b_n\), because these takes only 2 kind of values 0 or 1, it can be expressed as \(a_n = Q, b_n = Q*, Q** = Q\). Now \(a_n\neq p_n, b_n\neq q_n\), so \(p_n = Q*, q_n = Q\). But \(p_n= q_n\) should hold for the third logic of qbit. To solve this contradiction, we must say \(a_n = b_n\). Therefore, in summary, 
\[
 a_m \neq b_m\land \forall i\neq m\br{a_i=b_i}.
\]
It means \(\cbr{a, b}\in S_m\).

Then in the opposite case \(m\to n\), for the same indexes \(p, q, a, b\), using the property \(\cbr{p, a}\in S_n\) and \eqref{emg2},
\begin{align}
    \psi_{p}' &= \psi_p\cos\beta - \ci \psi_a \sin \beta.
\end{align}
Here, we know \((p, q), (a, b)\in S_m\), therefore, with \eqref{emg2} again,
\begin{align}
    \nonumber
    \psi_{p}' &= (\psi_p\cos\beta - \ci \psi_q \sin \beta)\cos\beta - \ci (\psi_a\cos\beta - \ci \psi_b \sin \beta) \sin \beta, \\
    \eqlabel{eqm2n}
    &= \psi_p \cos^2\beta - \psi_b\sin^2\beta -\ci\br{\psi_q\sin\beta\cos\beta + \psi_a\cos\beta\sin\beta}.
\end{align}

Because applying mixer operation in order of \(n, m\) (\eqref{eqn2m}) and that in order of \(m, n\) (\eqref{eqm2n}) give the same result, any pair of mixer operation to qbits \(m, n\) are commute. Because it is well known any permutation can be expressed with the finite combinations of such exchange, from the mathematical induction, any sequence of qbit order to apply mixer operation gives the identical result. 

\section{Pipeline element}
\label{spipe}
This section formalizes a timing of the pipeline as a mathematical function. The reason both cost function and mixer operator can be computed using the same pipeline introduced here is also explained at end of the section.

The pipeline is defined using the variables \(\phi, c, s, \chi, A\). Meanings are,
\begin{itemize}
    \item \(\phi\): amplitude of the state vector
    \item \(c\): Value of cosine or real part of cost function operator
    \item \(s\): Value of sine or imaginary part of cost function operator
    \item \(\chi\): Switch flag of first component of amplitude or that of second, or cost function.
    \item \(A\): Index (Address) of the amplitude place to be stored.
\end{itemize}
These variables form a series, like in a way, \(\phi_1, \phi_2, ..., \phi_T\), where  \(T\) is the number of pipeline depth. Subscript of \(1\) like \(\phi_1\) means input stage. This document use \('\) to indicate the next state in terms of discrete time on the clocks, like in a way \(\phi'\). 

Here, for example, to compute the mixer operation, the input is set as,
\begin{equation}
    \eqlabel{eminit}
    \begin{matrix}
        \phi_{1}' = \psi_\hatj\\
        c_1' = \cos\beta\\
        s_1' = \sin\beta\\
        \chi_1' = j_0\overline{j_0}\\
        A_1 = \hatj
    \end{matrix} 
\end{equation}
where \(\hatj\) is an index applied a permutation to \(j\), defined in section \ref{sAddrGen}. \(\overline{\cdot}\) means bit flipping operation, that is, \(\overline{1} = 0, \overline{0} = 1\). If \(q\) is successor index supplied to the pipeline and \(\chi_1' = 01\), it must be satisfied that \(\cbr{\hatj, q}\) is a set of indexes of the amplitudes to be mixed. That is, for some \(n\in[N]\), \(\cbr{\hatj, q}\in S_n\). In the opposite case of \(\chi_1' = 01\), with a preceeding index \(p\), the case \(\cbr{p, \hatj}\in S_n\) must hold. For more example, if the input is the last amplitude, \(\chi_1' = 10\) must hold, because the last element should compose a pair with preceeding one. The way above supplying \(\chi_1' = j_0\overline{j_0}\) will satisfy these cases.

We futher make the case \(\chi=00\) stands for cost function operation later, because this pipeline designed for mixer operation can be used only with slight modification. First this document describes the use of this pipeline in mixer operation.
Updating the pipeline values as,
\[
    \br{\phi, \chi, A, c, s}'_{\tau +1} = \br{\phi, \chi, A,c,s}_{\tau}, \tau=1,2,...,T
\]  \
then complex number operation is defined as following.
\begin{align}
    \eqlabel{ep00}
    \psi_{A_{T}}' &= \xi_{T} - \zeta_{T-1} &\Leftarrow \chi_T = 01,\\
    \eqlabel{ep01}
    \psi_{A_{T}}' &= -\zeta_{T+1} + \xi_{T} &\Leftarrow \chi_T = 10,\\
    \eqlabel{ep10}
    \psi_{A_{T}}' &= \xi_{T} +  \zeta_{T} &\Leftarrow \chi_T = 00,
\end{align}
where, 
\begin{equation}
    \xi_{\tau} = \phi_\tau c_\tau, \zeta_\tau = \ci\phi_\tau  s_\tau,
\end{equation}
must be calculated with 4 multipliers (note that there are 2 real and complex value multiplication. Complex values have 2 real numbers, real part and imaginary part.).
The notation \('\) means updated value, i.e., if we denote the time stamp as \(t\in\sN\), then \(\psi' = a\) means \(\psi^{t+1} = a^t\) in this context.

This pipline can be used also for cost function operation. For this, we set the inital values in the pipeline system as,
\begin{equation}
    \eqlabel{ecinit}
    \begin{matrix}
        \phi_{1}' = \psi_j,\\
        c_1' = \ORe(H_j),\\
        s_1' = \OIm(H_j),\\
        \chi_1' = 00,\\
        A_1 = j,
    \end{matrix} 
\end{equation}
where \(H_j\in\sC\) is a cost function operator.
When we apply the input with \eqref{eminit}, \eqref{ep00} and \eqref{ep01} is applied alternately to get a result for 2 mixed amplitude in this order. That is, setting \eqref{eminit} make the pipeline calculate 2 mixer operation with 2 clocks. The throughput is 1 per 1 clock. On the other hand, when we apply the input with \eqref{ecinit}, only \eqref{ep10} is applied 

\subsection{Non-stopping pipeline}
This subsection introduces another addressing by which the system does not need to stop the pipeline to flash the elements in its pipeline, for the case \(T < 2^{N-1}-1\). Basically \(T\) is fixed regardless of the state vector size \(D=2^N\) and usually \(T\approx 100\) and \(2^N > 10000\). So this condition is satisfied in the practical use.

Trivial sapping bits method introduced in the previous section \ref{sAddrGen} gives this condition \(T < 2^{N-1}\), while general bit permutation other than swapping or rotations may give more strict condition \(T < 2^{N/2}\). In this section only the case of the swapping is described and let the general worst case in \ref{sMinGen}.

It is assumed that the system is applying mixer operations of \(n, m=n+1\) in this order without flashing the pipeline before start \(n\)-th operation. If \(\cbr{p, q}\in S_n\) is the pair now the system will process, then there are indexes \(a, b\), such that \(\cbr{p, a}, \cbr{q, b}\in S_{m}\) as shown in section \ref{mixerInvariance}. To process mixer operation of \(n\)-th qbit for \(\psi_p, \psi_q\), these \(\psi_p, \psi_q\) must be finished mixer operation on \(m\)-th qbit in advance, that is, before the \(n\)-th mixer operation on \(p, q\), the pipeline need to have stored the results of \(\psi_p, \psi_q\) to the place where the pipeline can read again to make the computation consistent. More in general, to state that, not only \(\psi_a, \psi_q\), but also all 4 elements \(\psi_a, \psi_p, \psi_b, \psi_q\) must have been finished \(m\)-th mixer operation.

To see the timing formally, the document will formalize the schedule of indexes and value of qbit \(n\) supplied to the pipeline here. Let \(l^t, t\in[ND-1]\) be a series of indexes and \(q^t\) is a qbit that means \(q^t\)-th mixer operation is applied to \(\psi_{l^t}\) at the time \(t\). They are defined as,
\begin{align}
    \eqlabel{elt}
l^t &= \sigma(n)\br{r^t},\\
\nonumber
t & = q^t D + r^t, 0\leq r^t < D, q^t \in \sN.
\end{align}
where \(D = 2^N\) and \(r^t, q^t\) is the reminder and the quotient of division for \(t\) by \(D\). \(\sigma(n): B^N\to B^N\) is a permutation for \(n\)-th mixer operation (it also represents the permutation of \([N]\to [N]\), as explained in \eqref{ePerm}.), that must satisfy,
\[
    \sigma(n) n = 1.
\]

We let \( n=q^t\) for clearness of the description. Assuming we are processing \(t\)-th index of \eqref{elt}, for index \(l^t\), exists \(b\) such that \(\cbr{l^t, b}\in S_n\). To process this pair, for qbit \(m=n-1\), and some \(c, d\),  \(\cbr{l^t, c}, \cbr{b, d}\in S_m\), all of \(l^t, b, c, d\) must have finished the pipeline before the time \(t\). We let \(l^t = a\). Now the time the pipeline processed \(a, b, c, d\) are examined. Letting \(t_a, t_b, t_c, t_d\) are the time \(a, b, c, d\) were processed respectively, then, from the definition \eqref{elt},
\[
    l^{t_x} = x, x\in\cbr{a, b, c, d}
\]
The follwing quantities are defined.
\[
    Y_x = t - {t_x}, Y_* = \min\cbr{Y_x| x\in \cbr{a, b, c,d}} 
\]
We want to see, whether
\begin{equation}
    \eqlabel{eTabcd}
    Y_* > T. 
\end{equation}
holds or not. 

\(a, b, c, d\) have 2 expression using permutation of index, one of them for \(S_n\), the other is for \(S_m\). We denotes that for \(S_n\) as \(q^x\), and that for \(S_m\) as \(p^x\). That is,
\begin{equation*}
    x = \sigma(n)(q^x) = \sigma^m(p^x), x\in\cbr{a, b, c, d}.
\end{equation*}
We have the following equivalent relations,
\begin{equation}
    \eqlabel{eqprel}
    q^x = (\sigma(n))^{-1}\sigma^m(p^x), x\in\cbr{a, b, c, d}.
\end{equation}


If the reminder of \(t_x\) divided by \(D\) is \( = p^x\), then, from \eqref{elt}, 
\[
    t_x = (n-1) D + p^x.
\] 
Because \(r^t = q^a\) in \eqref{elt} (can be seen the current notation of \(l^t = a\)), we also have, 
\[
    t = n D + q^a.
\]
Therefore, 
\begin{equation}
    \eqlabel{etdiff}
Y_x = t - t_x  = q^a + D - p^x = 2^N + \sum_{k=1}^N 2^{k-1}\br{q^a_k - p^x_k}.
\end{equation}

\subsection{Case in swapping 2 bits}
We consider the case \(\sigma(n)\) is swapping \(n\)-th and \(1\)-st bits of its arguments as in section \ref{sAddrGen}. In this case \(\br{\sigma(n)}^{-1} = \sigma(n)\) and \(\sigma(n)\sigma(m)\) rotates \(1, m, n\)-th bits, that is, if \(h = \sigma(n)\sigma(m)\) then,
\[
    h(n) = 1, h(m) = n, h(1) = m, \forall i\in [N]_{1, m, n}.
\]
In this case from \eqref{eqprel}, we have, 
\begin{align*}
    q^x_n = p^x_m, q^x_m = p^x_1, q^x_1 = p^x_n, \forall i\in[N]_{1, n, m}\br{q^x_i = p^x_i}.
\end{align*} 

Furthermore, current conditions \(\cbr{a, b}\in S_n, \cbr{a, c}\in S_m, \cbr{b, d}\in S_m\) give the following,
\begin{align*}
    q^b_1 &= \bar{q^a_1}, \forall i\in [N]_1\br{q^b_i = q^a_i},\\
    p^c_1 &= \bar{p^a_1}, \forall i\in [N]_1\br{p^a_i = p^c_i},\\
    p^d_1 &= \bar{p^b_1}, \forall i\in [N]_1\br{p^b_i = p^d_i}.
\end{align*}


We want to express \(p^b, p^c, p^d\) using \(q^a\). To obtain these, combining relations above, we have,
\begin{align*}
    p^a_m = q^a_n, p^a_n = q^a_1, p^a_1 = q^a_m, \forall i\in[N]_{1, n, m}\br{p^a_i = q^a_i},\\
    p^b_m = q^a_n, p^b_n = \bar{q^a}_1, p^b_1 = q^a_m, \forall i\in[N]_{1, n, m}\br{p^b_i = q^a_i},\\
    p^c_m = q^a_n, p^c_n = q^a_1, p^c_1 = \bar{q^a_m}, \forall i\in[N]_{1, n, m}\br{p^c_i = q^a_i},\\
    p^d_m = q^a_n, p^c_n = \bar{q^a}_1, p^d_1 = \bar{q^a_m}, \forall i\in[N]_{1, n, m}\br{p^d_i = q^a_i}.
\end{align*} 

Substituting those above into \eqref{etdiff}, we have,
\begin{align*}
 Y_a = t - t_a  &= 2^N + 2^{n-1}\br{q^a_n - q^a_1} + 2^{m-1}\br{q^a_m - q^a_n} + (q^a_1 - q^a_m), \\
 Y_b = t - t_b  &= 2^N + 2^{n-1}\br{q^a_n - \bar{q^a_1}} + 2^{m-1}\br{q^a_m - q^a_n} + (q^a_1 - q^a_m), \\
 Y_c = t - t_c  &= 2^N + 2^{n-1}\br{q^a_n - q^a_1} + 2^{m-1}\br{q^a_m - q^a_n} + (q^a_1 -\bar{q^a_m}), \\
 Y_d = t - t_d  &= 2^N + 2^{n-1}\br{q^a_n - \bar{q^a_1}} + 2^{m-1}\br{q^a_m - q^a_n} + (q^a_1 -\bar{q^a_m}), \\
\end{align*}
Note that terms of \(k\in[N]_{1, n, m}\) vanished from the summation, because \(p^x_k = q^x_k\) for such \(k\).

From the lemma A, \(q_1^a = 1, q_n^a =0. q_m^a = 0\) will minimize \(Y_a\). Considering for the others as well, we have minimum values \(\ubar{Y}_x\) as,
\begin{align*}
\ubar{Y}_a &= 2^{N}- 2^{N-1} + 1 = 2^{N-1} + 1, \\
\ubar{Y}_b &= 2^N - 2^{N-1} = 2^{N-1},\\ 
\ubar{Y}_c &= 2^{N} - 2^{N-1} = 2^{N-1},\\
\ubar{Y}_d &= 2^N - 2^{N-1} - 1 = 2^{N-1} -1.
\end{align*}
Therefore, \(Y_*\) in \eqref{eTabcd} takes the value, \(Y_* = 2^{N-1} -1\). \(T < 2^{N-1} -1\) is the sufficient condition the system does not need to stop the pipeline to flash its internal data before starting the next qbit processing. For \(N=7\), the condition is for example \(T < 65\). Note that our pipeline at 500 MHz now have the latency \(T \approx 60\), which satisfies the condition. For more detail in general case of permutations, we have a condition 
\begin{equation}
    \eqlabel{eTinGen}
    T < 2^{N/2}.
\end{equation}
The proof is provided in section \ref{sMinGen}. In the case of rotation, I expect similar order, \(Y_* \approx 2^{N-1}\) (Proof will take time but in the same manner.). General case gives much stricter condition. So we are recommended to utilize swapping or rotation permutation.


\section{Addressing for parallel processing}
Letting \(K=2^M\) be a number of parallel blocks. In naive implementation like in bottom of Fig. \ref{f1}, if we parallelized the system in \(K=2^M\) blocks, the system need inter local memory (like BRAMs) access \(M\)-times both for read and write. The implementation describes here reduce it to \(1\) regardless of \(M\). Whole blocks work parallelly and there is no serial processing in this implementation either. Fundamental idea to this tricky implementation is that, exchange local qbits and global qbits after completing the computing of local qbits. After processing global qbits (place in local qbits), back qbits to the original places. In other words, it re-arrage memory assignment for each amplitude of the state vector at the time of transfer for greater qbits that is used to divide the system into blocks (such qbits refers to global qbits here.).



\subsection{Block Mixing Algorithm} 
\label{sBMA}
We describe an alogorithm tentatively called block mixing algorithm here after in the section. It consists of local mixer, shuffling, global mixer, and restoration.
We prepare \(K = 2^M\) pipeline blocks defined in the section \ref{spipe}.  
In these definitions, we can formalize the mixer operation that provide the possible implementation for \(K = 2^M \leq 2^\hatM\) parallelization with \(K\) blocks. 

In this document the \(\hatM\)-th greatest bits are called global qbits. Remaining \((N-\hatM)=L\) bits are called local qbits. Dimension of space that global qbits compose can be greater than number of parallel blocks, thus, \(K = 2^M \leq 2^\hatM\).

\textit{Local mixer}: letting 
\[j=0,1,...,2^{N-\hatM}-1\]
 be an local index, 
and \[k=0,1,...,2^{\hatM}-1\]
 be an global index. In the local mixer stage, using the index,
\[
\jbar = k\hatj,
\]
mixer operations are applied to \(n\in[L]\ (L=N-\hatM)\) qbit for each \(k\)-th block (\(\hatj\) is defined in the same way as in section \ref{sAddrGen}). Note that only the part of \(\hatj\) above is used to access BRAMs. For intuitively, consider the case \(k = 5=101, j=11001\), then this notation means \(\jbar = 10111001\). 
In this stage, each block of pipeline includes several \(k\), where for special case of \(\hatM = M\), \(k\) is equivalent to the identification of each pipeline block.

\textit{shuffling}: 
The system will re-arrange the state vector as in,
\begin{equation}
    \eqlabel{esigma}
    \psi^{\sigma}_\jbar = \psi_{\sigma(\jbar)}.
\end{equation}
\(\sigma:\cbr{0,1}^N\to\cbr{0,1}^N\) is a permutation and defined so that it shuffle the indexes. Precisely, it is defined as,
\begin{align*}
    \sigma\br{p_N \cdots p_1} &= p_{N-\hatM}\cdots p_1 p_N\cdots p_{N-\hatM+1},\\
    \sigma^{-1}\br{p_N\cdots p_1} &= p_{\hatM}\cdots p_1 p_N\cdots p_{\hatM+1}.
\end{align*}
Superscript \(\sigma\) of \(\psi\) just indicates \(\psi^\sigma\) is obtained by applying \(\sigma\). 

Assuming we got \(\psi\in \sC^D\) as an initial state vector and got \(\psi^L\in\sC^D\) by applying mixer operation to the local qbits (qbit such that its number \(n\) satisfies \(n\leq \hatM\).). Superscript \(L\) means the vector applied \(L\) bits local mixer operation. Then, let \(\psi^{\sigma L}\) be a state vector that shuffled its amplitude position as,
\begin{equation}
    \eqlabel{eshuffle}
    \psi^{\sigma L}_\jbar = \psi^L_{\sigma(\jbar)} , \Leftrightarrow\psi^{\sigma L}_{p_N\cdots p_1}= \psi^L_{p_{N-\hatM}\cdots p_1 p_N\cdots p_{N-\hatM+1}}
\end{equation}
where we took the representation of,
\[
\jbar = p_N\cdots p_1.
\]
\textit{Global mixer}: 
Then we apply mixer operation on the qbits of \(n \in[\hatM]\) to \(\psi^{\sigma L}\) and we obtain \(\psi^{\hatM\sigma L}\). It can be done as completely same as in the case of local mixer. In detail, 
\[j=0,1,...,2^{\hatM}-1\] be an local index (for originally global), 
and \[k=0,1,...,2^{N-\hatM}-1\]
 be an global index (originally local). In this stage, the following index,
\[
\jbar = k\hatj,
\] 
is used to addressing in section \ref{sAddrGen} for each \(k\)-th block. Note that only the part of \(\hatj\) above is used to access BRAMs.

\textit{Restoration}: Let \(\psi^{\sigma^{-1}\hatM\sigma L}\in\sC^D\) be a final result of original order, it can be obtained,
\begin{equation}
    \eqlabel{ereverseshuffle}
\psi^{\sigma^{-1}\hatM\sigma L}_\jbar = \psi^{\hatM\sigma L}_{\sigma^{-1}(\jbar)}, \Leftrightarrow \psi^{\sigma^{-1}\hatM\sigma L}_{p_N\cdots p_1}= \psi^{\hatM\sigma L}_{p_{\hatM}\cdots p_1 p_N\cdots p_{\hatM+1}}.
\end{equation}

Let \(\psi^N\) be a result of mixer operation without global qbits. Then, we claim that,
\begin{equation}
    \eqlabel{eblockmixA}
\psi^N = \psi^{\sigma^{-1}\hatM\sigma L}.
\end{equation}
This proposition holds and it is proved here after in the section \ref{sProofBMA}.

\subsubsection{Sammary of Block Mixing Algorithm}
Copying data performed in \eqref{eshuffle} and \eqref{ereverseshuffle} to exchange global and local qbits require computational cost. But this copy process can be in parallel. About the amount of data to be copied, for example, \(1/K\) is remained in the original block, and elements amount \(1-1/K\) should be moved to another block. But this copy is only once for shuffling (\eqref{eshuffle}) and restoring (\eqref{ereverseshuffle}), it should be the least cost among any parallel algorithm on distributed systems in this order of parallelization \(K\). If it compares to the naive implementation (Fig. \ref{f1} bottom right) in which each mixer operation for each qbit needs access to inter BRAM, because such qbit by qbit operation needs \(M\ (K=2^M)\) times access totally, this proposed algorithm reduced the chance of global access at the ratio \(1/K\). 

Cost function operation can be applied at the stage of restoration between the period after fetching a data from another BRAM and storing it to the original position of the original BRAM. e.g., \(N=2^{20}\) which is a practical number of qbits, we can take \(\hatM=2^{10}\) which ordinally above the available blocks for parallelization. Note that takes \(\hatM > M\), where \(M\) is the number of physical blocks, is not a problem. We can see that there is no problem in such configuration \(\hatM > M\) in the mathematical proof of the algorithm later.
 
If we can set \(\hat{M} = N/2\), way of pipline do is totally the same as for both of operations on global and local qbits.

\subsubsection{Proof of Block Mixing Algorithm yeilds the same result that do not use global qbits}
\label{sProofBMA}
To prove this, we need to define mixer operation for qbit \(n\) more generally. Mixer operation on \(n\)-th qbit is expressed as \(U_n\). And from the result of invariance on mixer operation in section \ref{mixerInvariance}, we have,
\begin{equation}
    \eqlabel{emixcomm}
 U_n U_{m}\psi = U_m U_n\psi  
\end{equation}
We denote operation exchanging qbits \(n, 1\) as \(\Theta_{n, 1}\), then
we want to show,
\begin{equation}
    \eqlabel{einvn1}
    U_n \psi = \Theta_{n, 1} U_{1} \Theta_{n, 1}\psi .
\end{equation}

\textbf{Proof.}  From the definition of mixer operator \eqref{emg2}, \( U_n \psi\) is described  for all index \(p = 0,1,...,{D-1}, q, \cbr{p, q}\in S_n\) (such \(q\) exists uniquely) as,
\begin{align*}
    \br{U_n \psi}_p &= \psi_p \cos\beta - \ci\psi_q \sin \beta.
\end{align*}
When applying \(\Theta_{n,1}\), from its definition of exchanging, there exist indexes \(a, b=0,1,...,D-1\) that satisfy for arbitrary \(h\in\sC^D\), 
\begin{align}
    \nonumber
    \br{\Theta_{n, 1}h}_{p} &= h_{a}, a_N\cdots a_1 = p_N\cdots p_{n+1}p_1 p_{n-1}\cdots p_2 p_n,\\
    \eqlabel{epqab}
    \br{\Theta_{n, 1}h}_{q} &= h_{b}, b_N\cdots b_1 = q_N\cdots q_{n+1}q_1 q_{n-1}\cdots q_2 q_n.
\end{align}
Now we know \(p_n\neq q_n\) from definition \eqref{eSn}, so it can be seen \(a_1 \neq b_1\) holds from the fact \(p_n = a_1, q_n=b_1\) above equations. Similarly, \(\forall i\in N_n,  a_i=b_i\). It means \(\cbr{a, b}\in S_1\). Therefore,
\begin{align*}
    \br{U_1 h}_{a} & = h_a \cos\beta - \ci h_b \sin \beta\quad \because \cbr{a, b}\in S_1\land \eqref{emg2}\\
    &= \br{\Theta_{n, 1} h}_p\cos\beta - \ci\br{\Theta_{n, 1}h}_q \sin \beta.\because\eqref{epqab}\\
   \therefore \br{\Theta_{n,1} U_1 h}_{p} & = \br{\Theta_{n, 1} h}_p\cos\beta - \ci\br{\Theta_{n, 1}h}_q \sin \beta.
\end{align*}
We can substitute \(h = \Theta_{n,1}\psi\) without changing the domain the above equation defined because \(\Theta_{n,1}\) is a bijection of \(\sC^D\to\sC^D\). With that fact and applying \( \Theta_{n,1}\Theta_{n,1}\psi = \psi\), then, for all \(\psi\in\sC^D\),
\begin{align*}
   &\br{\Theta_{n,1} U_1 \Theta_{n,1}\psi }_{p}  = \br{\psi}_p\cos\beta - \ci\br{\psi}_q \sin \beta = \br{U_n \psi}_p.\because \cbr{p, q}\in S_n\\
   &\therefore \Theta_{n,1} U_1 \Theta_{n,1}\psi = U_n \psi.
\end{align*}
So we proved \eqref{einvn1}.

Letting \(\Theta_{n, m}\) is an operator exchanging \(n\) and \(m\)-th qbit index, then it can be composed as \(\Theta_{n, m} = \Theta_{n, 1}\Theta_{m, 1}\Theta_{n, 1}\). Using this fact and \eqref{einvn1}, we have the follwing general case,
\begin{align}
    \eqlabel{e1nm}
    &U_n \psi = \Theta_{n, m}  U_{m} \Theta_{n, m}\psi\\
    \nonumber
    &\because U_n \psi=\Theta_{n, 1} U_{1} \Theta_{n, 1}\psi = \Theta_{n, 1} \Theta_{m, 1}\Theta_{n, 1} U_{m} \Theta_{n, 1}\Theta_{1, m}\Theta_{n, 1}\psi = \Theta_{n, m}  U_{m} \Theta_{n, m}\psi 
\end{align}

We also want to show,
\begin{equation}
    \eqlabel{eln1}
l \not\in\cbr{n, 1}\Rightarrow \Theta_{n, 1} U_l = U_l \Theta_{n, 1}.
\end{equation}
\textbf{Proof.}  \( U_l \psi\) is described as for all index \(u = 0,1,...,{D-1}, v, \cbr{u, v}\in S_l\) (such \(v\) exists uniquely),
\begin{align*}
    \br{U_l \psi}_u &= \psi_u \cos\beta - \ci\psi_v \sin \beta.\quad\because \eqref{emg2}
\end{align*}
When applying \(\Theta_{n, 1}, l\not\in\cbr{n, 1}\), there exist indexes \(c, d=0,1,...,D-1\) that satisfy for arbitrary \(h\in\sC^D\), 
\begin{align*}
    \br{\Theta_{n, 1}h}_{u} &= h_{c}, c_N\cdots c_1 = u_N\cdots u_{n+1}u_1 u_{n-1}\cdots u_2 u_n,\\
    \br{\Theta_{n, 1}h}_{v} &= h_{d}, d_N\cdots d_1 = v_N\cdots v_{n+1}v_1 v_{n-1}\cdots v_2 v_n.
\end{align*}
Now we know \(c_n=d_n, c_1=d_1\) because it follows the above equation with the fact \(u_n = v_n, u_1=v_1\) from the definition of \(S_l\) in \eqref{eSn} and the current assumption \(l\not\in \cbr{n, 1}\). The above equation and \eqref{eSn} also claims that \(c_l = u_l, d_l= v_l, u_l\neq v_l\), therefore we have \(c_l\neq d_l\). For another cases, \(\forall i\in N_l,  c_i=d_i\). It means \(\cbr{c, d}\in S_l\) too. Therefore,
\begin{align*}
    \br{U_l h}_{c} & = h_c \cos\beta - \ci h_d \sin \beta\quad \because \cbr{c, d}\in S_l\\
    &= \br{\Theta_{n, 1} h}_u\cos\beta - \ci\br{\Theta_{n, 1}h}_v \sin \beta.\\
   \therefore \br{\Theta_{n,1} U_l h}_{u} & = \br{\Theta_{n, 1} h}_u\cos\beta - \ci\br{\Theta_{n, 1}h}_v \sin \beta.
\end{align*}
We can substitute \(h = \Theta_{n,1}\psi\) because \(\Theta_{n, 1}\) is a bijection and applying \( \Theta_{n,1}\Theta_{n,1}\psi = \psi\), then, 
\begin{equation}
   \br{\Theta_{n,1} U_l \Theta_{n,1}\psi }_{u}  = \br{\psi}_u\cos\beta - \ci\br{\psi}_v \sin \beta = \br{U_l \psi}_u. \because \cbr{u, v}\in S_l
\end{equation}
Therefore, \eqref{eln1} holds. Similarly it can be generalized from \(1, n\) to \(m, n\), as following, 
\begin{equation}
    \eqlabel{elnm}
l \not\in\cbr{n, m}\Rightarrow \Theta_{n, m} U_l = U_l \Theta_{n, m}.
\end{equation}

Rotation can be expressed as finite multiplications of such exchange \eqref{elnm} and \eqref{e1nm}. Therefore, if \(R_n\) is a rotation operator that rotate index \(n\in[N-1]\) times, it also satisfies, 
\begin{equation}
    \eqlabel{erotateB}
    U_{n} \psi = R_{-n+1}  U_{1} R_{n-1}\psi,
\end{equation}
where,
\begin{align*}
\br{R_{n}\psi}_{p_N\cdots p_1} &= \psi_{p_{N-n}\cdots p_1p_N\cdots p_{N-n+1}},\\
\br{R_{-n}\psi}_{p_N\cdots p_1}&= \psi_{p_{n}\cdots p_1p_N\cdots p_{n+1}},\\
R_1 &= \Theta_{2,1}\cdots\Theta_{N-1, N-2}\Theta_{N, N-1}\\
R_{n+m} &= R_n R_m
\end{align*}
Note that this \(R\) corresponds to \(\sigma\) in \eqref{esigma} and \(R_{-n}= \br{R_n}^{-1}\). Combining \eqref{emixcomm} with this result \eqref{erotateB}, we see,
\[
    U_{N}U_{N-1} \psi = R_{-(N-2)}  U_{2}  R_{N-2}R_{-(N-2)}U_{1} R_{N-2}\psi =R_{-(N-2)}  U_{2} U_{1} R_{N-2}\psi ,
\]
and by mathematical induction, 
\begin{equation}
    \eqlabel{erotate}
    U_{N}\cdots U_{N-\hatM+1} \psi = R_{-(N-\hatM)} U_{\hatM} \cdots U_{1} R_{N-\hatM}\psi.
\end{equation}.

Now we can write \eqref{eblockmixA} formally. The 2 quantities (result without global qbits, and result with global qbits) in \eqref{eblockmixA} are defined formally as,
\begin{align*}
    \psi^N &=  U_{N}\cdots U_{1} \psi\\
    \psi^{\sigma^{-1}\hatM\sigma L} &= \br{R_{-(N-\hatM)} U_{\hatM} \cdots U_{1} R_{N-\hatM} }U_{N-\hatM} \cdots U_1 \psi.
\end{align*}
But we have \eqref{erotate}, therefore, 
\begin{align*}
    \psi^{\sigma^{-1}\hatM\sigma L} &= R_{-(N-\hatM)} U_{\hatM} \cdots U_{1} R_{N-\hatM} U_{N-\hatM} \cdots U_1 \psi\\
    & =  U_{N}\cdots U_{N-\hatM+1}  U_{N-\hatM} \cdots U_1 \psi \quad\because \eqref{erotate}\\
    & =  U_{N}\cdots U_1 \psi 
\end{align*}
It implies \(\psi^N = \psi^{\sigma^{-1}\hatM\sigma L}\ (L=N-\hatM)\) (\eqref{eblockmixA}).

We can see, comparing first one and the second one, total data transfer is reduced from \(32\) to \(24\). Number of mixer operations is the same. The number of synchronizations is reduced to \(6\) to \(3\). In summary, the second one outperforms the first one. In general case assuming \(M < N/2\), if \(K=2^M\), letting \(\hat{Q}_{\text{all}}\) be data transfer exchanging \(M\) global qbits \textit{all at once} with local qbits, it is, 
\begin{equation}
    \eqlabel{eQall}
    \hat{Q}_{\text{all}} = \frac{D}{K^2} K (K-1) = \frac{D(K-1)}{K} \approx D.
\end{equation}
On the other hand, letting \(\hat{Q}_{\text{1b1}}\) be that by \textit{one-by-one} strategy, it is,
\begin{equation}
    \eqlabel{e1by1}
    \hat{Q}_{\text{1b1}} = \frac{D}{2K} K\times K = \frac{DK}{2}
\end{equation}
Intuitively, imagine, \(K\) parallel means each block have \(D/K\) elements. In the case of \textit{all at once}, \(1/K\) part is transferred, so \(D/(K^2)\) elements transferred to the other blocks. This will occur between any pair of blocks. So with the combination of \(K(K-1)\), \eqref{eQall} obtained. For \textit{one-by-one} case, size of the block is the same as the case of all at once, \(D/K\). In each transfer, half of the contents must be transferred, so \(D/(2K)\) is transferred. This will occurs in \(K\) blocks at once, and the procedure repeated \(K\) times, so \eqref{e1by1}. \(\hat{Q}_{\text{all}}\) is independent of \(K\) and has the constant number of synchronization, 2. In addition, the data transfer for \(\hat{Q}_{\text{all}}\) utilizes all data buses available in the system, while that for \(\hat{Q}_{\text{1b1}}\) utilizes part of the data busses. There is no reason to select the strategy of \(\hat{Q}_{\text{1b1}}\) instead of \(\hat{Q}_{\text{all}}\).

 \hat{Q}_{\text{all}} &= \# \cbr{p| p_{N:N-M+1} = k, p_{N-M:N-2M+1} = k', p\in B^N, k\neq k'} \\
&= \# \cbr{kk'| k\neq k', k, k'\in B^M}\times\# \cbr{q|q\in B^{N-2M}}.
\end{align*}
The first factor is considered. All possible \(k, k'\) is \(K^2\). Subtract the case \(k=k'\), which exists \(2^M = K\), we have \(K^2 - K = K(K-1)\). The second factor is \(2^{N-2M} = D/(K^2)\).

For \eqref{e1by1},

&= \# \cbr{kk| k = aq, k'=bq, k\neq k' q\in B^{M-1},a, b\in B}\times \#\cbr{q| q\in B^{N-M-1}}\times K.\\
\end{align*}
 The number of distinct pair of \(k, k', k\neq k'\) is \(2^{M+1} - 2^M = 2^M = K\).  The second factor is has the size \(2^{N-M-1}\). So \( Q(k\to k') = 2^{N-M-1} = D/(2K)\). It is repeated \(K\) times. So the above holds.

\section{Problem of Memory bandwidth}
The problem of memory bandwidth in our FPGA is discussed. As a result I recommend to challenge to the memory bandwidth should be in the future work.

Recent demand to memory bandwidth is really huge. To respond the demand, manufactures have tried their best to increase the memory bandwidth of their products, in the level from 120 GB/s to 2 TB/s.

Our FPGA, Stratix 5, only implements 64 bits data bus for external DDR memory with 1600 MHz. It means, \(64\times 1600 \mathrm{Mbits}/s = 12.8 \mathrm{GB/s}\)is the maximum theoretical speed to the external memory. In the case of BRAM, we have more than 16 K bits of bus for BRAM and maximum clock of 500 Mhz, the maximum bandwidth of BRAM is \(8 \mathrm{TB/s}\) even in our relatively old FPGA. This is far faster than memory bandwidth of current state-of-the-art GPU's external memory. If we implement our Algorithm, it may outperform even modern processors with our relatively old FPGA for the small case of qbits which can be stored only in BRAMs. Order of \(2^{16}\) qbits can be in BRAMs for example.

Speaking to the pipeline defined in section \ref{spipe}, it already has the data processing speed of \(8 \mathrm{GB/s}\), when it runs at 500 MHz. Because it processes 128 bits data per 1 clock, the performance is \(128 \mathrm{bit}/ (8 \mathrm{bit/B}) \times 0.5 \mathrm{GHz} = 8 \mathrm{GB/s}\). Therefore, if we use external memory without any caching mechanism to hide the memory speed bottleneck (12.8 GB/s), increasing the pipeline does not provide meaningful improvement on the speed. Possible method to cover up the low speed of external DDR memory is using block mixing described so far in the section \ref{sBMA}, because it also can be used to reduce the amount of access to the global memory space. For example, if we set the number of local qbit to \(M\), the maximum reduction of speed is \(1/M\). In the case \(M=8\) which is possible number, the memory speed can be seen up to \(8\times 6.4 = 51.2 \mathrm{GB/s}\), though it is still far slower even than modern CPUs having around 100 GB/s commonly. Of course CPUs cannot utilize theoretical speed whereas our implementation always does. However, we are recommended to plan to obtain modern FPGA environment if we talk about external memory. We still can consider algorithm for the future replacement of the FPGA and can also try basic experiments on our current FPGA. Such experiments should give us enough insight that allows us to implement our architecture on the new FPGA immediately. Trial on Multi-FPGA solution should much beneficial.

\subsection{Sufficient condition of the mixer pipeline in general index permutation}
\label{sMinGen}
This section provides a proof \eqref{eTinGen}. Because this proof is complex, and the result does not have practical benefit, it is recommended for the reader of the document to see this section only if you have special technical reason.

As in \eqref{etdiff}, we only consider \(\cbr{a, b}\in S_n\). By doing so, at least we can prove \(2^{N/2} > T\) is a sufficient condition not to make the pipeline to wait flashing its data before going to the next qbit.  

Relate \(a = l^t, n = q^t\) for \(l^t, q^t, t\) in \eqref{elt}. Let \(\tau, \lambda: B^N\to B^N\) are bijective mapping in \eqref{elt} defines \(n\) and \(m=n-1\)-th index operation respectively,  and make equivalent permutations of \([N]\to [N]\) be represented with the same symbols \(\tau, \lambda\) respectively. Then because \(\cbr{a, b}\in S_n\) and \(\exists c, \cbr{a, c}\in S_m\), there are \(p, q\in B^N\) having the relation,
\begin{equation}
    \eqlabel{eapp1}
 a_i = \tau(q) = \lambda(p) \Leftrightarrow a_i = q_{\tau i} = p_{\lambda i}. 
\end{equation}
The time difference \(Y_b\) of \eqref{etdiff} is then,
\[
Y_b = p + (D - q) = 2^{N} + \sum_{k=1}^N 2^{k-1}(q_k - p_k)
\]
Substituting \eqref{eapp1},
\[
Y_b = 2^{N} + \sum_{k=1}^N 2^{k-1}(q_k - q_{\lambda \tau^{-1} k}) .
\]

We discusse the lower bound of summation term here after.

\textbf{Lemma B}: Let \(N\in\sN\), \(h:[N]\to [N]\) be a bijection. For any \(x\in B^N\), 
\begin{equation}
\eqlabel{eLB}
A(x) = 2^N + \sum_{k=1}^N 2^{k-1} (x_k - x_{hk}) \geq 2^{N/2 } - 1.
\end{equation}

\textbf{Proof}: we divide summation in 2 parts. There is a subset \(L'\subset[N], y\in B^N\) that satisfy,
\[
    \forall k\in L', y_k - y_{h k} = -1.
\] 
Let \(L\) be a largest subset among those \(L'\) above. 
Then we see for any \(k\in L\), \(y_k = 0, y_{hk} = 1\). Therefore, \(L \cap h L = \emptyset\). Because \(h\) is a bijection, \(\# L = \# hL\), and \(L + h L \subset [N]\). Therefore, \(\# L \leq N/2\). 

Because we cannot take \(L\) with \(> N/2\). Consider \(h, y\) for example such that, with \(\hat{N} = \max \cbr{X| X \leq N/2, X\in [N]}\), for \(i \in[\hat{N}]\)
\begin{equation}
    \eqlabel{eLh}
    hi = N-i+1,  h (N-i+1) =i, y_i = 1, y_{N-i+1} = 0.
\end{equation}
In this, \(hL = [\hat{N}], L = \cbr{N,...,N-\hat{N}+1}\). This \(L\) is the largest one from lemma A in section \ref{slemmaA}, this \(L, y\) supply the minimum value of \(A\). Actually, taking an example \(L, y\) as \eqref{eLh}, 
\begin{align*}
A(y) &\geq 2^N + \sum_{k\in L}^N 2^{k-1} (y_k - y_{hk})  + \sum_{k\in hL}2^{k-1}(y_k - y_{hk}) - 2^{\hat{N}} \\
&= 2^N - \sum_{k=N-\hat{N}+1}^{N} 2^{k-1}  + \sum_{k=1}^{\hat{N}} 2^{k-1} - 2^{\hat{N}}\\
&= 2^N - 2^{N} + 2^{N-\hat{N}} + 2^{\hat{N}} - 1 - 2^{\hat{N}}\\
&= 2^{N-\hat{N}}  - 1\\
&\geq 2^{N/2}  - 1. \quad\because N/2 \leq N- \hat{N}.
\end{align*}

Substituting \(h = \lambda\tau^{-1}\) in Lemma B above is possible because \(\lambda\tau^{-1}\) is a bijection. Also substituting \(y = q^a\), we have \(Y_a = A(q^a) > 2^{N/2}-1\). Because we are talking the minimum value of \(Y_a\) for every possible permutations, the proof makes \eqref{eTinGen} a sufficient condition the pipeline does not need to stop with any index permutation. This is far strict than the condition of \(T < 2^{N-1}\) assuming the permutation is just a swap. Therefore, it is recommended to consider specific permutation that sufficiently provide necessary property of the computation.

\subsection{Proof of the condition that parallel block mixing algorithm enable non-stopping pipeline}

Consider the permutation,
\[
\sigma(p_O \cdots p_1\ k_M\cdots k_1) = k_M\cdots k_1\ p_O\cdots p_1, k\in B^M, p\in B^O, O = N-M,
\]
for block mixing. 
Let \(a\) be an index now the system needs to process at the time \(t\) with the permutation \(\sigma\), and \(t_a\) is the time \(a\) processed last time with the permutation \(\tau\), where we are assuming \(\tau\) is a swapping used in mixer operation, so it is bijective. Consider \(a\) have the 2 expressions, \(a = \sigma q = \tau p\). hence we have, 
\[
    t_a = (n-1)E + p, t = n E  + q, E = 2^{O}
\] 
\[
    t - t_a = q + E - p  = 2^O + \sum_{j=1}^O 2^{j-1}(q_j-p_j).
\]
\[
\sigma q = q_O\cdots q_{M+1} \cdots k_M\cdots k_1, \tau p = p_1 p_{O-1}\cdots p_2 p_O.
\]
This section provides 2 cases of \(\tau\), one case (A) for \(\tau\) is a swapping used in mixer operation. Applicatoin with such swapping as \(\tau\) means \(\sigma\) is used between 2 mixer operations. Another case (B) is to chose one of identity mapping or \(M\)-th and \(1\)-st bits swapping for \(\tau\). This corresponds to that block mixing with \(\sigma\) will appear before the beginning of the mixer layer, and intermadiate period of the mixer operations just after \(M\)-th local qbits. The second case corresponds to the process introduced in the Section \ref{sPracticalChoise}. Here after this shows case (A) first, then case (B).

Because \(\sigma\) is not an bijective, it does not have inverse mapping. We consider \(\tau^{-1}\sigma q =  p\) because \(\tau\) is a bijection mapping. Then it is,
\[
 \tau^{-1}\sigma q  = k_1 q_{O-1}\cdots q_{M+1} \cdots k_M\cdots k_2 q_O
\]
therefore, 
\begin{align*}
 t - t_a &= 2^O + 2^{O-1} (q_O - k_1) + \sum_{j=2}^{M} 2^{j-1}(q_j-k_j) + (q_1 - q_O) 
\end{align*}
we consider the minimum value of the above. The instance is, 
\[
q_O = 0, k_1 = 1, q_1 = 0, \forall j\in M_2(q_j = 0, k_j = 1).
\]
So, we have, 
\begin{align*}
 t - t_a &\geq 2^O - 2^{O-1} - \sum_{j=2}^{M} 2^{j-1} + 0 \\
 &\geq 2^{N-M-1} - 2^{M} + 2. \because O = N-M.
\end{align*}
A little strict than the serial case of \(2^{N-1}\). \(M=2, N = 8\), then, \(t - t_a = 30.\) \(M=2, N=9 \Rightarrow t-t_a = 62\). \(M=6, N=16 \Rightarrow t-t_a = 450\).
